# Portfolio latihan

Ini portfolio contoh milik Fahdin. Isinya masih bisa dikembangkan, jadi pilih satu bagian yang ingin kamu bantu lalu ajukan perubahan lewat pull request.

## Menjalankan

Buka `index.html` di browser. Tailwind CSS dan GSAP diambil dari CDN, jadi perlu koneksi internet. Belum ada proses build.

## Aturan kontribusi

1. Pilih satu tugas dan kabari fasilitator sebelum mulai.
2. Buat satu pull request untuk satu tugas.
3. Cek tampilan di komputer dan ponsel sebelum mengirim pull request.
4. Bicarakan dulu jika perubahanmu menambah dependency atau mengubah arah desain.
5. Jika mengubah animasi, pastikan halaman tetap nyaman saat gerakan dikurangi di pengaturan perangkat.

## Daftar tugas

1. [ ] **Lengkapi profil Fahdin.** Perbarui lokasi, deskripsi, email, dan tahun setelah mendapat informasi yang disepakati.
2. [ ] **Perbarui tautan sosial.** Ganti tautan Instagram dan LinkedIn dengan akun yang benar.
3. [ ] **Buat halaman detail proyek.** Pilih satu karya, buat halaman ceritanya, lalu hubungkan dari halaman utama.
4. [ ] **Ceritakan proses proyek.** Tambahkan latar belakang, peran, proses, dan hasil tanpa mengarang angka.
5. [ ] **Buat visual proyek baru.** Ganti ilustrasi yang ada dengan visual berdasarkan bahan proyek dan beri keterangan yang jelas.
6. [ ] **Rapikan navigasi di ponsel.** Pastikan semua tautan mudah digunakan dengan sentuhan dan keyboard.
7. [x] **Tunjukkan bagian yang sedang dibaca.** Buat penanda navigasi yang membantu pengunjung mengetahui posisinya.
8. [ ] **Tambahkan pengalaman.** Susun pengalaman kerja atau kolaborasi agar mudah dibaca.
9. [x] **Lengkapi informasi kontak.** Tambahkan cara menghubungi Fahdin dan pastikan tautan email tetap berfungsi.
10. [ ] **Periksa aksesibilitas.** Cek kontras, urutan judul, fokus keyboard, dan keterangan tautan.
11. [ ] **Cek tampilan layar kecil.** Uji lebar 320 piksel dan posisi mendatar, lalu perbaiki bagian yang terpotong atau sulit dibaca.
12. [ ] **Tambahkan ikon dan metadata halaman.** Siapkan ikon situs serta gambar dan teks untuk pratinjau tautan.
13. [ ] **Percepat pemuatan halaman.** Cari cara mengurangi kebutuhan CDN tanpa menyulitkan orang yang ingin mencoba proyek.

Untuk tugas yang membutuhkan bahan asli, minta kontennya dulu kepada fasilitator. Kalau punya usul lain, diskusikan sebelum mulai agar tidak bertabrakan dengan pekerjaan anggota lain.
